# Agrolink Africa – AI-Powered Agricultural Ecosystem

Official enterprise website repository for **Agrolink Africa**.

## Overview
Agrolink Africa connects the entire agricultural value chain with predictive AI—forecasting crop demand, reducing post-harvest losses, and connecting smallholder farmers to commercial buyers.

### Key Features
* **Predictive AI Demand Advisory**: Real-time market demand forecasting and climate telemetry.
* **Inclusive Agri-Tech**: Offline 2G USSD (*384*254#) and SMS accessibility for rural smallholders.
* **Omnichannel Value Chain Matching**: Seamless connection between smallholders, commercial producers, buyers, and cold chain logistics.
* **Escrow Settlement**: Guaranteed mobile money (M-Pesa) payouts upon harvest delivery.
* **Nationwide Pilots**: Active deployments in Kiambu, Nakuru, and Meru counties.

## Running Locally
```bash
python3 serve.py
```
Then open [http://localhost:8080/](http://localhost:8080/) in your browser.
